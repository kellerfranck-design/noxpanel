# NoxPanel — téléchargements officiels / official downloads

**FR** — Ce dépôt distribue NoxPanel, logiciel gratuit de Nox-Lab qui transforme une tablette Android en panneau de commandes pour Windows. Il ne contient que des fichiers de distribution : les versions publiées (onglet *Releases*) et le catalogue des profils (`catalog/`). Aucun code source.

- Téléchargez uniquement depuis l'onglet *Releases* de ce dépôt ou depuis le site officiel de NoxPanel.
- Vérifiez l'empreinte SHA-256 publiée avec chaque version, par exemple dans PowerShell : `Get-FileHash .\NoxPanel-Installation.zip -Algorithm SHA256`.
- L'installateur vérifie lui-même chaque fichier avant de l'installer ; les mises à jour automatiques ne sont installées que si leur signature est valide.
- Les profils du catalogue sont vérifiés (empreinte et signature) par NoxPanel avant installation.

**EN** — This repository distributes NoxPanel, free software by Nox-Lab that turns an Android tablet into a control panel for Windows. It only holds distribution files: published versions (*Releases* tab) and the profile catalogue (`catalog/`). No source code.

- Download only from this repository's *Releases* tab or from the official NoxPanel website.
- Check the SHA-256 hash published with each version, e.g. in PowerShell: `Get-FileHash .\NoxPanel-Installation.zip -Algorithm SHA256`.
- The installer checks every file before installing; automatic updates are only installed if their signature is valid.
- Catalogue profiles are checked (hash and signature) by NoxPanel before installation.

Compatible game names belong to their owners. NoxPanel is independent and not affiliated with them.
